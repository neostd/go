# NeoStd Go Modules

- **[cmdargs](./cmdargs/README.md)** - command line arguments
- **[crypto](./crypto/README.md)** - encryption, password hashing, and secret sharing
- **[dotenv](./dotenv/README.md)** - dotenv parsing and document editing
- **[env](./env/README.md)** - environment variable expansion and path helpers
- **[exec](./exec/README.md)** - command execution, piping, and executable
- **[xscript](./xscript/README.md)** - cross-platform exec scripts (ruby, typescript, groovy, golang, csharp, python, bash, pwsh, etc

The official repo is at https://github.com/neostd/go

The licenses are located under each module directory and are
generally MIT.
